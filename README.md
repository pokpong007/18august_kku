# ชุดโค้ดสนามและหุ่นยนต์ Arduino UNO

โปรเจกต์นี้เตรียมโค้ดจากแบบสนามใน `ออกแบบสนามหุ่นยน.pdf` ครบ 4 สนามย่อย ทั้งฝั่งกลไกของสนามและฝั่งหุ่นยนต์สองล้อ

พินของหุ่นยนต์ถูกกำหนดจาก `DINCRobot.h/robot_pins.ino` เท่านั้น ไม่มีการเพิ่มปุ่มหรือเซนเซอร์บนหุ่นยนต์ พิน D3 เป็น IR remote ที่ไม่ได้ใช้ ส่วน D10 ใช้หมุน servo ของหัว ultrasonic ตามฮาร์ดแวร์จริงในภาพ

## ไฟล์พร้อมใช้

| สนาม | โค้ดสนาม | โค้ดหุ่นยนต์ | หน้าที่หลัก |
|---|---|---|---|
| 1 วงเวียน | `arduino/field/field_1_roundabout/` | `arduino/robot/field_1_roundabout_robot/` | นับ 2 รอบ เปิดห้องปุ่ม แล้วเปิดทางออก |
| 2 สะพาน | `arduino/field/field_2_bridge/` | `arduino/robot/field_2_bridge_robot/` | สวิตช์ 2 จุด ลดสะพาน/เปิดประตูหลังหน่วง 3 วินาที |
| 3 ห้องประตูคู่ | `arduino/field/field_3_dual_gate/` | `arduino/robot/field_3_dual_gate_robot/` | ลิมิตสวิตช์ 2 จุดควบคุมประตูน้ำเงินและเขียว |
| 4 เขาวงกต | `arduino/field/field_4_timed_gate/` | `arduino/robot/field_4_maze_robot/` | อัลตราโซนิกสั่ง buzzer นับถอยหลังและเปิดไม้กั้น แล้วหุ่นยนต์เกาะผนังขวา |

ถ้าเพิ่งเริ่ม ให้เปิด [คู่มือเริ่มจากศูนย์](คู่มือเริ่มจากศูนย์.pdf) ซึ่งเรียงตั้งแต่ต่อสาย อัปโหลด คาลิเบรต ทดสอบสนาม ไปจนถึงลำดับปล่อยรถจริง

จำนวนอุปกรณ์ยึดตาม `listของiot for สนาม - Sheet1.pdf`: ใช้ UNO สนาม 4 จาก 6 ตัว, servo 7 จาก 9 ตัว, breadboard 4 ตัว, ultrasonic ทั้ง 3 ตัว และสวิตช์รวมทั้ง 5 ตัว ปุ่มรีเซ็ตให้ใช้ปุ่ม `RESET` ที่มีอยู่บน UNO แต่ละสนาม ไม่ต้องต่อปุ่มภายนอกเพิ่ม รายละเอียดอยู่ในหัวข้อ 5 ของคู่มือ

## เริ่มใช้งานแบบสั้น

1. ใน Arduino IDE ไปที่ **Sketch > Include Library > Add .ZIP Library...** แล้วติดตั้ง `output/arduino-libraries/DINCRobot.zip` และ `DINCField.zip` อย่างละหนึ่งครั้ง เพื่อให้ IDE รู้จักไฟล์ `.h` ของทุกสเก็ตช์.
2. เลือกบอร์ด **Arduino UNO**.
3. เปิด `.ino` ของสนามหรือหุ่นยนต์ที่ต้องการแล้ว Upload.
4. ทดสอบสนามโดยถอดก้านเซอร์โวออกก่อน ตรวจ LED/มุมหมุน แล้วจึงประกอบก้านจริง.
5. เปิด `arduino/tools/robot_calibration/robot_calibration.ino` เพื่อทดสอบด้วยคำสั่ง `f`, `l`, `r`, `u`, `s` ผ่าน Serial Monitor แล้วแก้ค่ารวมที่ `[Sketchbook location]/libraries/DINCRobot/src/RobotSettings.h` เพียงไฟล์เดียว

การควบคุมหุ่นยนต์เป็นแบบ hybrid: ใช้เซนเซอร์เดิมตรวจประตู ผนัง สวิตช์ และจุดสิ้นสุดแบบ dynamic ส่วนระยะกลางพื้นที่โล่งและการเลี้ยวยังคงใช้ค่าคาลิเบรตตามเวลา เพราะชุดพินเดิมไม่มี encoder หรือ IMU สำหรับวัดตำแหน่งและมุมโดยตรง

ไฟล์ `.ino` จะเห็นกันเองเมื่ออยู่ในโฟลเดอร์สเก็ตช์เดียวกัน ส่วน `.h` และ `.cpp` ของชุดนี้อยู่ใน Arduino library ที่ต้องติดตั้งก่อน ไม่ต้องคัดลอกไฟล์เหล่านี้เข้าไปในโฟลเดอร์ของแต่ละสนาม วิธีนี้ใช้ได้ทั้ง Windows และ macOS

โฟลเดอร์เดิม `DINCRobot.h/` ถูกเก็บไว้โดยไม่แก้ไข ส่วนต้นฉบับ Arduino library อยู่ใน `arduino/libraries/` และไฟล์ ZIP พร้อมติดตั้งอยู่ใน `output/arduino-libraries/`.
